# Funny Pages fonts and textures

These files are served with the Funny Pages preview from
`/assets/themes/funny-pages/`. Both faces are SIL Open Font License 1.1.
The license text shipped with each upstream family is beside this note.
Infuser did not draw these faces, and the CSS does not fetch them from a CDN.

- `bangers-latin.woff2` — Bangers, Copyright 2010 The Bangers Project Authors
  (https://github.com/googlefonts/bangers). Latin subset, original family
  name kept.
- `comic-neue-400-latin.woff2` and `comic-neue-700-latin.woff2` — Comic Neue,
  Copyright 2014 The Comic Neue Project Authors
  (https://github.com/crozynski/comicneue). Weights 400 and 700, Latin subset,
  original family name kept.

`halftone.svg` and `newsprint.svg` are original textures.
