# Field Notes fonts and rules

These files are served with the Field Notes preview from
`/assets/themes/field-notes/`. Both faces are SIL Open Font License 1.1.
The license text shipped with each upstream family is beside this note.
Infuser did not draw these faces, and the CSS does not fetch them from a CDN.

- `newsreader-400-latin.woff2` and `newsreader-700-latin.woff2` — Newsreader,
  Copyright 2020 The Newsreader Project Authors
  (http://github.com/productiontype/Newsreader). Weights 400 and 700, Latin
  subset, original family name kept.
- `caveat-700-latin.woff2` — Caveat, Copyright 2014 The Caveat Project Authors
  (https://github.com/googlefonts/caveat). Weight 700, Latin subset, original
  family name kept.

`ruled.svg` is an original notebook rule.
