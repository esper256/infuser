# Castle Keep fonts and textures

These files are served with the Castle Keep preview from
`/assets/themes/castle-keep/`. Both faces are SIL Open Font License 1.1.
The license text shipped with each upstream family is beside this note.
Infuser did not draw these faces, and the CSS does not fetch them from a CDN.

- `medievalsharp-latin.woff2` — MedievalSharp, Copyright (c) 2011, wmk69
  (wmk69@o2.pl), with Reserved Font Name MedievalSharp. Latin subset,
  original family name kept.
- `nunito-400-latin.woff2` and `nunito-700-latin.woff2` — Nunito, Copyright
  2014 The Nunito Project Authors (https://github.com/googlefonts/nunito).
  Weights 400 and 700, Latin subset, original family name kept.

`stone.svg`, `grass.svg`, `oak.svg`, `steel.svg`, and `parchment.svg` are original textures.
