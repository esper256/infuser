# Fonts in this throwaway prototype

These files are not wired into Infuser. They exist so the Cartridge Club
mockups can load a real face from the same origin, the way a theme asset
route would. Both faces are SIL Open Font License 1.1. The license text
shipped with each upstream family is beside this note. Infuser did not draw
these faces, and the CSS does not fetch them from a CDN.

- `lilita-one-latin.woff2` — Lilita One, Copyright (c) 2011 Juan Montoreano,
  Reserved Font Name "Lilita". Latin subset, original family name kept.
- `fredoka-600-latin.woff2` — Fredoka, Copyright 2016 The Fredoka Project
  Authors (https://github.com/hafontia/Fredoka-One). Weight 600, Latin subset.

`shelf.svg` and `grain.svg` are original textures made for this prototype.
