# Infuser Play updates

Audience: players and admins.

Install Infuser Play once. When opened, it checks for a new published release at
most once an hour, then downloads and starts the update automatically. The window
shows progress; no second installer or administrator password is needed.

Updating preserves account connections and saves, and does not interrupt running
games. Game downloads and updates happen separately when you press Play.

If an update check fails, the installed copy remains usable. If the new app fails
to start, Infuser Play tries its previous version. The Windows preview is unsigned
and may show a Windows security prompt.

Preview installations from before automatic updates were added need the current
installer once. Later releases update themselves.
