# Native typography

Unmodified Noto Sans Regular and Bold, from Debian's `fonts-noto-core` package
(upstream: https://github.com/notofonts/noto-fonts). Both are licensed under the
SIL Open Font License 1.1; see `OFL.txt`. Copyright and licensing information also
remain embedded in each font's name table.

The native app embeds these fonts to keep text weight and layout consistent on
Windows and Linux. Egui's existing fallback fonts remain available for glyphs
outside their coverage.
