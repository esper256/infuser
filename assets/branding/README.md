# Infuser identity

The approved direction is **05 — Open World**, preserved in
`open-world-concept.png`: a mint open rounded-square mark with two escaping
pixels, a navy background, and a rounded warm-white lowercase `infuser` wordmark.
Keep this direction as shown. The cream/green Open Space variant was not chosen.

This image is the approved concept board, including its caption. It is not yet
a production favicon or a vector wordmark. Splash artwork should use this
identity while leaving space for the login UI.
